# Suricata Log Analysis

## Log Files

The lab included examination of the following Suricata logs.

### fast.log

A human-readable alert log that records alerts generated by
Suricata rules.

### eve.json

A structured JSON event log containing information about
network events and alerts.

### stats.log

Contains Suricata statistics.

### suricata.log

Contains Suricata operational and diagnostic messages.

## Analysis Approach

The lab involved inspecting fast.log and formatting EVE JSON
records using jq.

The purpose was to improve readability and understand how
Suricata records network activity.

See `EVE_JSON_LOG_REPORT.md` for the dedicated EVE JSON report.
