# Troubleshooting Notes

This document provides a place to record issues encountered
during the lab and their verified resolutions.

## Recording an Issue

For each issue, record:

1. The command or operation involved.
2. The exact error message.
3. What was investigated.
4. The confirmed resolution.
5. Supporting evidence, where available.

## Accuracy

Only confirmed resolutions should be documented as solved.
Do not record a suggested solution as a successful fix unless
it was tested.
