# Suricata EVE JSON Log Analysis Report

## 1. Introduction

This report documents the examination and analysis of Suricata's
`eve.json` log file during the Cyber Operations Lab.

The EVE (Extensible Event Format) JSON log records network events
detected and processed by Suricata.

The objective was to inspect recorded network activity, examine
event details, and understand how structured JSON logs support
network monitoring and security analysis.

## 2. Log File Location

The EVE JSON log is normally stored at:

```bash
/var/log/suricata/eve.json
```

## 3. Tools Used

- Suricata IDS: Network intrusion detection and event logging.
- EVE JSON: Structured event log generated by Suricata.
- jq: Command-line JSON processor used to format and inspect JSON.
- Linux Terminal: Used to access and examine the log file.

## 4. Installation of jq

The jq utility was installed to make JSON output easier to read.

```bash
sudo apt install jq
```

## 5. Log Inspection

The EVE JSON log was inspected and formatted using:

```bash
sudo cat /var/log/suricata/eve.json | jq
```

This pipeline reads the EVE JSON log and passes its contents
to jq for readable formatting.

## 6. Event Analysis

Depending on the event type and available fields, EVE JSON records
may contain:

- Timestamp: When the event was recorded.
- Event type: The category of the recorded event.
- Source IP: The originating IP address.
- Destination IP: The receiving IP address.
- Protocol: The network protocol involved.
- Source and destination ports: Port information where applicable.
- Alert information: Detection details when a rule generates an alert.

The lab included traffic-generation and rule-testing activities
involving TCP, UDP, ICMP, HTTP, SSH, and DNS.

Actual event details should be interpreted from the captured
log output and supporting screenshots.

## 7. Purpose of JSON Formatting

Formatting the EVE JSON output with jq makes nested event
information easier to inspect.

It improves readability and helps an analyst identify relevant
fields without manually interpreting a single-line JSON record.

## 8. Security Monitoring Relevance

EVE JSON provides useful data for:

- Reviewing network activity.
- Investigating IDS alerts.
- Identifying communicating hosts.
- Examining protocol activity.
- Supporting incident investigation.
- Collecting evidence for security analysis.
