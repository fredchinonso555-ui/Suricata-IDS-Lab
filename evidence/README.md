# Lab Evidence

This directory contains supporting evidence for the Suricata
IDS Cyber Operations Lab.

## Screenshots

Place original screenshots in:

`screenshots/`

## Evidence Guidelines

- Use genuine screenshots from the actual lab.
- Do not fabricate command output.
- Keep screenshots clear and readable.
- Use descriptive filenames.
- Remove sensitive information before publishing.

The evidence should support the activities described in
the documentation and reports.
