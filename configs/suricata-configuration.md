# Suricata Configuration

## Configuration File

```text
/etc/suricata/suricata.yaml
```

## Navigation

The configuration file was reached using step-by-step navigation:

```bash
cd /etc
ls
cd suricata
ls
nano suricata.yaml
```

## Default Rule Path

The absolute default rule path was configured in the Suricata
configuration file using Nano.

Documented path:

```text
/var/lib/suricata/rules/
```

## Purpose

The default rule path tells Suricata where to locate its rule files.

The configuration should be compared with the original lab screenshot
before deployment or reuse.
