# Contribution Guidelines

Contributions should improve the clarity, accuracy, and reproducibility
of this lab documentation.

## Guidelines

1. Do not fabricate command output or screenshots.
2. Clearly distinguish tested configurations from examples.
3. Document commands and their purpose.
4. Keep reports readable and technically accurate.
5. Do not include passwords, private keys, or sensitive personal data.
6. Keep screenshots in `evidence/screenshots/`.
7. Update the relevant README when adding new sections.

## Reporting Issues

Describe the issue, the affected file, and the steps required
to reproduce it.
